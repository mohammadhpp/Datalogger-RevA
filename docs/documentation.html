Reading order

  1. Read the README for the public purpose and status.
  2. Read AI_START_HERE for project continuity rules.
  3. Read the latest CURRENT_HANDOFF for the authoritative current exact point.
  4. Confirm relevant decisions in DECISIONS_AND_CONSTRAINTS and consult original engineering evidence before claiming any PASS.

What lives in the repository?

The public GitHub repository contains Altium schematic sheets, the tracked RevA PCB and library, maintenance scripts, handoff documents and historical evidence. Not every file is intended as user-facing documentation, and public visibility does not automatically grant an open-source license.

Important: the current handoff filename is AI_CONTINUITY/CURRENT_HANDOFF.md. Do not assume a file called CURRENT_HANDOFF_v6.md is the authoritative document.
