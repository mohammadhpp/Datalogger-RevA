Datalogger RevA

Battery-powered embedded data logger hardware project: SHT3x environmental sensing, STM32, microSD, RTC, OLED interface, and Altium Designer PCB engineering.

Explore the GitHub repository →
Engineering status: This project is under development as of October 2026. Electrical acceptance, physical prototype validation, and fabrication readiness have not been established. Do not use historic BOMs or model outputs as approved manufacturing instructions.

Project features and goals

Environmental sensing

Temperature and relative humidity measurement using the SHT3x sensor family.

Data storage

Targeting timestamped logging with a real-time clock and a microSD interface.

Embedded interface

STM32 microcontroller architecture, OLED display, and physical navigation keys.

Power architecture

USB and battery operation with seamless handoff as a design goal, not a verified capability.

PCB design

Cost-conscious two-layer Altium PCB; alternative single-layer power test coupons are being investigated.

Engineering records

Schematics, PCB libraries, handoff notes, scripted checks, and explicitly labeled validation evidence.

About the project

Datalogger RevA documents the evolution of an embedded temperature and humidity data-logging board, including PCB layout, power-path exploration, package selection for manual assembly, and engineering test planning. It is presented for technical reference and project transparency; no claim of manufacturing or electrical certification is made.
