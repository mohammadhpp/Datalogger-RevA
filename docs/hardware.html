Hardware architecture and features

A compact embedded temperature-and-humidity data logger in development, combining sensor input, timestamped storage and a local interface.

Functional blocks

Sensor input

SHT3x-family temperature and relative-humidity sensing. The documented internal sensor connection is a labeled six-pin, 2.54 mm through-hole connector; the external panel connector is a separate interface.

Microcontroller and controls

An STM32-based control architecture with physical navigation keys and an OLED interface. A completed PCB layout is not proof of firmware or system functionality.

Storage and timestamps

microSD storage and an RTC are part of the project design. Successful data writing and retention during power-source transitions have not yet passed full hardware validation.

Power input and handoff

Battery operation and standard USB or power-bank input are planned, with USB prioritization and return to battery without resetting the MCU. This behavior remains an engineering acceptance target.

PCB and assembly constraints

The established RevA PCB baseline is two copper layers and manual assembly. Silkscreen identifiers, component polarity and connector orientation must remain readable; off-board devices need explicit PCB-side interfaces. The active Altium source, not a web diagram, governs design changes.

Package accessibility, copper clearances, practical rework space and in-country component sourcing are important considerations, but proposed replacement components are not approved merely because a package appears hand-solderable.

Single-layer laser power test coupons

Separate test boards are being evaluated for one-copper-layer fiber-laser and etching work. The documented preliminary concepts are a 35 × 25 mm process-isolation coupon, a 70 × 50 mm power-mux/load carrier, and separate 45 × 40 mm USB buck and battery boost board studies.

Important: These dimensions are preliminary. There is no completed single-layer routed PCB, copper Gerber or drill output. The 0.20 mm feature-clearance process must be tested, and switching converters may require small two-layer modules if return-path and layout constraints cannot be met.

Source: T25DA single-layer feasibility analysis.
